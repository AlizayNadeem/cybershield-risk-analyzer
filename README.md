A Python-based cybersecurity incident risk analyzer
# CyberShield - Security Incident Risk Analyzer

## Overview
CyberShield is a beginner-friendly Python project that
evaluates cybersecurity incidents using a simple risk score.

## Features
- Accepts an incident name.
- Collects impact and likelihood ratings.
- Calculates a risk score out of 25.
- Classifies incidents into four risk levels.
- Suggests an action for each risk level.
- Validates the rating values.

## Risk Classification
- Critical: 20-25
- High: 12-19
- Medium: 6-11
- Low: 1-5

## Requirements
- Python 3

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project directory.
3. Run:

   python cybershield.py

## Disclaimer
This project demonstrates basic risk scoring for educational
purposes. It does not replace a professional security assessment.
